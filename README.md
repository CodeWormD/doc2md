# DOC2MD — локальный конвертер документов в Markdown

Локальный веб-сервис: превращает **Excel, Word и PDF** в «плоский» Markdown,
оптимизированный для чтения языковыми моделями (минимум токенов, максимум смысла).
Всё работает на вашей машине — файлы никуда не отправляются.

## Поддерживаемые форматы

| Формат | Чем читается | Особенности |
|---|---|---|
| `.xlsx` `.xlsm` | openpyxl | все листы; формулы — как последние сохранённые значения; даты → ISO |
| `.xls` (старый) | xlrd | те же правила |
| `.csv` | встроенный csv | автоопределение разделителя; UTF-8 / cp1251 / UTF-16 |
| `.docx` | mammoth | заголовки, списки, таблицы, жирный/курсив; картинки отбрасываются |
| `.doc` (старый) | MS Word через COM | нужен установленный Word; файл сначала конвертируется в .docx |
| `.pdf` | PyMuPDF | таблицы → markdown-таблицы; фильтр колонтитулов и номеров страниц |

## Что делает вывод «дешёвым» для LLM

- таблицы — настоящие markdown-таблицы (Excel-листы, таблицы из DOCX и PDF);
- пустые строки/столбцы обрезаются, лишние пустые строки схлопываются;
- даты приводятся к компактному ISO (`2024-01-15`), числа без хвостового `.0`;
- из PDF удаляются повторяющиеся колонтитулы и «хвостовые» номера страниц
  (`3`, `- 5 -`, `стр. 7`, `Page 12 of 40`);
- картинки не извлекаются (в сценарии «прочитать текстом» они только жгут токены).

## Запуск

Нужен Python 3.10+ (проверено на 3.12).

**Самый простой способ** — двойной клик по `start.bat`:
при первом запуске он сам создаст виртуальное окружение, установит зависимости
и откроет браузер на `http://127.0.0.1:8765`.

Вручную:

```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python app.py
```

Если порт 8765 занят, сервис автоматически выберет следующий свободный (8766, …).

## Как пользоваться

1. Перетащите файл на страницу (или нажмите на зону выбора).
2. Дождитесь конвертации — увидите markdown, статистику (символы, слова, ≈токены).
3. **«Сохранить как…»** — диалог выбора места (Chrome/Edge) или скачивание в «Загрузки»;
   «Копировать» — в буфер обмена.

Опции:
- *Убирать колонтитулы и номера страниц* — для PDF (по умолчанию вкл).
- *Отмечать страницы PDF* — вставляет `<!-- стр. N -->` между страницами (по умолчанию выкл).

Файл загружается во временную папку и удаляется сразу после конвертации.

## API (для автоматизации)

```bash
curl -F "file=@отчёт.xlsx" http://127.0.0.1:8765/convert
```

Ответ — JSON: `markdown`, `warnings[]`, `stats{chars, words, tokens_est, seconds}`,
`download_name`. Ошибки — `415` (формат) / `422` (понятная причина) с текстом в `error`.

## Известные ограничения

- `.doc` без установленного Microsoft Word не откроется — пересохраните в `.docx`.
- Сканы PDF (без текстового слоя) не читаются — нужен OCR.
- Формулы Excel читаются как их последние вычисленные значения (если книга не
  пересчитана при сохранении, значения могут быть пустыми).
- Оценка токенов приблизительная (символы ÷ 3.5).

## Структура

```
doc2md/
├── app.py               # Flask-сервер (страница + POST /convert)
├── converter.py         # конвертеры xlsx/xls/csv/docx/doc/pdf
├── requirements.txt
├── start.bat            # запуск одним кликом (venv + зависимости + старт)
├── templates/index.html # веб-интерфейс
└── tests/
    ├── make_samples.py  # генерация тестовых файлов (dev, python-docx отдельно)
    ├── samples/         # тестовые файлы
    └── out/             # результаты тестов
```
